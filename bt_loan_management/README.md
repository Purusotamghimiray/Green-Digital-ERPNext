# BT Loan Management - ERPNext 16 Custom Module

Complete Frappe/ERPNext 16 custom app for tracking external loan repayments and BT scheme remittances (BDBL, BoB, NPPF, Druk PNB, BTL) and generating the exact DHI repayment schedule report.

## Installation
```bash
bench get-app bt_loan_management
bench --site [your-site] install-app bt_loan_management
bench --site [your-site] migrate
```
