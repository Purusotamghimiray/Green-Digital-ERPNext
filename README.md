# Green Digital ERPNext

Custom applications developed for Frappe and ERPNext, focusing on Bhutan-specific business requirements.

## Applications

### 1. Bhutan Payroll (`bhutan_payroll`)

Bhutan-specific payroll customizations, salary processing enhancements, and reports for ERPNext.

### 2. Bhutan Loan Management (`bt_loan_management`)

Employee loan management, external loan tracking, repayment schedules, remittance management, and reporting.
